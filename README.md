# Делопад

Планировщик задач для Android 12 и новее: ежедневник, задачи без даты, виджет, уведомления, будильники и повторяющиеся задачи.

[Скачать последнюю версию](https://github.com/Keyrrin1001/delopad-releases/releases/latest)

В разделе Releases выберите APK. Для обновления установите его поверх прежней версии, сохранив приложение и его данные.

Начиная с версии 0.6.9: Настройки → Обновление приложения → Проверить обновление → Скачать и установить обновление. Android попросит подтвердить установку; впервые может потребоваться разрешение устанавливать обновления из Делопада. Вход в GitHub для скачивания не нужен.

Этот публичный репозиторий хранит готовые APK и сведения об обновлениях. Задачи пользователей сюда не передаются. Проверка обновления обращается к GitHub только по команде пользователя.

Локальные резервные копии сохраняются по запросу. Облачные копии сохраняются в аккаунте Google самого пользователя; на текущем этапе подключение Google доступно приглашённым тестировщикам.

Сведения об авторах встроенных звуков доступны внутри приложения: Настройки → О приложении → Авторы звуков.
